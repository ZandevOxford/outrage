# Project files

These files are copied from the root of the Outrage repository so the installed
documentation carries the project overview, licence and release history that
belong to its version.

* [README](project/readme.md) - the project overview and installation guide.
* [Licence](project/license.md) - the terms under which Outrage is distributed.
* [Changelog](project/changelog.md) - the release history and current
  unreleased changes.

The copies are generated by the documentation build and should not be edited
in this directory.
